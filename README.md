# Re:boot — лендинг тонировочно-установочной студии

Полноэкранный одностраничный сайт для студии **Re:boot**
(Екатеринбург, улица Ткачей, 14 · ежедневно 10:00–20:00, по предварительной записи).

Один файл `index.html` — разметка, стили и скрипты, без сборки и зависимостей.
Сверху — первый экран с фото, ниже — услуги, прайс, работы, отзывы и форма заявки.

## Что внутри

```
index.html             весь сайт (HTML + CSS + JS)
assets/
  photos/              фото работ (галерея) + фон первого экрана (hero.jpg)
  favicon.svg
functions/api/lead.js  Cloudflare Pages Function — приём заявок → Telegram
tools/leads-server.mjs локальный сервер: отдаёт сайт и принимает заявки
```

## Запуск локально

```bash
node tools/leads-server.mjs        # http://localhost:4181
```

Этот сервер не только отдаёт сайт, но и принимает заявки из формы: показывает их
в консоли и дописывает в `заявки.csv` (открывается в Excel).

Подойдёт и любой статический сервер, но тогда форма не сможет отправлять заявки:

```bash
python -m http.server 4180
```

## Заявки → Telegram

Форма отправляет данные `POST`-ом на `/api/lead`. Дальше заявка уходит владельцу
в Telegram: **услуга, имя, телефон, марка авто и время**.

Чтобы включить Telegram:

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Узнайте `chat_id` (например, через [@userinfobot](https://t.me/userinfobot)).
3. Задайте переменные окружения `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`
   — локально в окружении, на хостинге в настройках проекта.

```powershell
$env:TELEGRAM_BOT_TOKEN="123456:ABC…"
$env:TELEGRAM_CHAT_ID="123456789"
node tools/leads-server.mjs
```

Без этих переменных всё работает: заявки просто пишутся в CSV и в консоль.

## Публикация

Сайт статический — подойдёт любой хостинг (GitHub Pages, Cloudflare Pages, Netlify,
nginx). Для Cloudflare Pages достаточно указать папку проекта: функция
`functions/api/lead.js` подхватится автоматически.
